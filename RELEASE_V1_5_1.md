# Correctif V1.5.1 — Recette utilisateur

- La **marge par mission** est affichée correctement à chaque modification et après rechargement (persistée sous forme décimale). Le champ de marge globale est déjà lié à `deployment.margin`.
- Dans le **Suivi commercial**, récurrence du rappel : une fois, quotidien, **tous les deux jours**, hebdomadaire, bimensuel ou tous les 30 jours. Lorsqu'un rappel arrive à échéance, utiliser « Reporter » pour planifier la prochaine occurrence.
- Ajout de la **progression du projet** avec étapes commerciales, navigation étape précédente/suivante, et ajout d'étapes particulières à un projet. Distincte de la complétude.
- Les versions précédentes des projets sont compatibles ; aucune migration destructive requise.
- Les alertes s'affichent **dans l'application uniquement** ; pas de rappel automatique quand elle est fermée.
